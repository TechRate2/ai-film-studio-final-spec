# Series Story Logic

Long-form continuity is causal and informational, not only visual.

Track what changed in plot, relationship, knowledge, objective, resources/props, injury/outfit/location and unresolved promises. Episode endings should create a meaningful new state/question; next episodes resume that state rather than reset characters.

Character knowledge is directional: one character can know a secret another does not. A relationship can evolve differently in each direction.

Retcons create new canon versions and dependency invalidation; they do not erase production history.

Use summaries/snapshots for context efficiency but retain canonical structured facts underneath so summaries cannot silently distort truth.
