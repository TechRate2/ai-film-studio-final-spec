# Canonical Completeness Checklist

Use before declaring a spec release canonical.

## Product/brain
- one Director; provider-neutral ports; scope/content/production modes separated;
- research ROI/evidence/freshness; CreativeStrategy/StyleDNA/grammar/taste;
- short/long/series memory/canon/knowledge/relationship/active context.

## Media production
- ingestion/reference roles/locks/lifetimes;
- ProductionStrategy/GenerationPlan;
- selective all-source keyframes;
- UniversalVideoSpec/model compiler/provider adapter/effective capability;
- continuity DAG/Baton/Sandwich/version/staleness;
- voice/localization/audio/editorial/timeline/final QA.

## Spend/reliability
- cost estimate, SpendAuthorization, PaidAttemptGuard;
- candidate count policy;
- durable jobs/restart/cancel/callback/idempotency;
- paid-state certainty/reconciliation/fallback;
- no blind paid retry.

## Commercial operations
- tenant/media authorization/secrets;
- rights/consent/source provenance/content safety;
- retention/deletion;
- backup/restore/observability/spend kill switch.

## Coding-agent governance
- exact manifest/version counts;
- 43 numbered tasks intact;
- phase order reflects safety dependencies;
- traceability maps every critical behavior;
- golden scenarios cover regressions;
- JSON schemas parse;
- time-sensitive model claims carry verification status.
