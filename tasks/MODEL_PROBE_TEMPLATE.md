# Model Probe Template

Run controlled probes when a model/version/provider exposure is new or materially changed.

Minimum probes where supported/relevant:
1. reference binding/negative scope;
2. practical reference count stability;
3. stage vs timestamp timing adherence;
4. default camera/aesthetic/subtitle/music behavior;
5. duration reliability/event-density ceiling;
6. identity/product consistency;
7. first/end frame;
8. continuation/reference-video behavior;
9. native/ref audio/dialogue;
10. failure/timeout/billing semantics at provider layer.

Persist prompt/spec/profile/provider versions, inputs, outputs, latency, raw cost, QA metrics and accepted seconds. Do not promote anecdotal one-off success to global capability truth.
