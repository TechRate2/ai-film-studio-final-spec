# Reference Roles

## Retrieve when
Mixed references may control unintended attributes. Match decision need, not a hardcoded niche branch.

## Decision
Bind artifact versions to entities, positive controls, exclusions, lock and target lifetime; distill camera/style-only video.

## Trade-offs and when not to use
Do not merge lookalikes, copy reference backgrounds or use role-ambiguous full packs for convenience.

## Output and check
Record the chosen mechanism, reason and source skill version in the relevant CreativeStrategy, UniversalVideoSpec or timeline decision. Compiled bindings preserve controls/exclusions and expired/unrelated refs are absent.
