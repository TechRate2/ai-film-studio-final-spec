# Canonical Glossary

**Generalist Director** — single visible creative/production brain orchestrating tools.  
**Scope Intelligence** — SHORT/LONG_SINGLE/SERIES depth decision.  
**Content Mode** — drama/UGC/ad/product-demo/explainer/etc.; separate from generation mode.  
**Production/Generation Mode** — T2V/I2V/reference/continuation/S2V/mixed/existing-media route.  
**Project Canon** — versioned authoritative story/world truth.  
**ActiveContextPack** — smallest versioned subset of canon/entities/relationships/refs needed for the active decision.  
**Character Knowledge State** — what one character knows/believes/suspects/misunderstands/hides/wants/fears independently of world truth.  
**ReferenceBinding** — reference role + lock + lifetime + positive/negative control scope.  
**StyleDNA** — transferable creative/camera/edit/audio mechanisms extracted from references, excluding do-not-copy elements.  
**CreativeEvidenceGraph** — scoped reusable relations from evidence/context to mechanism/creative choice/outcome.  
**Continuity Baton** — accepted observed output state passed to dependent generation.  
**Continuity Sandwich** — previous accepted exit + revision intent + next accepted required start.  
**ProductionStrategy** — provider-neutral decision about which media/generation methods solve each scope at acceptable quality/cost.  
**GenerationPlan** — duration/boundary/dependency/keyframe/reference execution plan for generated media.  
**UniversalVideoSpec** — provider/model-neutral shot generation contract.  
**ModelProfile** — measured model behavior/capability/bias/failure knowledge.  
**ProviderProfile** — provider API exposure/price/limits/billing/transport knowledge.  
**EffectiveCapability** — intersection of model capability, provider exposure, account entitlement and product/project policy.  
**Prompt Compiler** — converts UniversalVideoSpec into model-specific prompt/reference/audio format.  
**Artifact Currency** — CURRENT/STALE/MISSING/BLOCKED.  
**SpendAuthorization** — user-approved scope/cap covering planned first billable attempts.  
**PaidAttemptGuard** — cost/authorization/idempotency/upstream reconciliation boundary around billable calls.  
**CompositionTimeline** — durable deterministic edit/audio/subtitle/export plan.  
**FinalMaster** — exported master tied to accepted timeline, QA and checksum/provenance.  
**cost_per_accepted_second** — total relevant generation cost divided by accepted usable video seconds.  
**Golden Scenario** — canonical behavioral regression scenario.  
**EvidencePack** — distilled, ranked and provenance-carrying research knowledge supplied to the Director.  
**ResearchROIController** — decides whether new research/probe is worth cost/latency and when to stop.
