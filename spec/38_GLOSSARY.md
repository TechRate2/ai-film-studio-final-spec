# Canonical Glossary

**Generalist Director** — single visible creative/production brain orchestrating tools.  
**Scope Intelligence** — SHORT/LONG_SINGLE/SERIES depth decision.  
**Content Mode** — drama/UGC/ad/explainer/etc.; separate from generation mode.  
**Production/Generation Mode** — T2V/I2V/reference/continuation/S2V/mixed route.  
**Project Canon** — versioned authoritative story/world truth.  
**Character Knowledge State** — what one character knows/believes/suspects independently of world truth.  
**ReferenceBinding** — reference role + lock + lifetime + positive/negative control scope.  
**Continuity Baton** — accepted observed output state passed to dependent generation.  
**Continuity Sandwich** — previous accepted exit + revision intent + next accepted required start.  
**UniversalVideoSpec** — provider/model-neutral shot generation contract.  
**ModelProfile** — measured model behavior/capability/bias/failure knowledge.  
**ProviderProfile** — provider API exposure/price/limits/billing/transport knowledge.  
**Prompt Compiler** — converts UniversalVideoSpec into model-specific prompt/reference/audio format.  
**Artifact Currency** — CURRENT/STALE/MISSING/BLOCKED.  
**PaidAttemptGuard** — cost/approval/idempotency/upstream reconciliation boundary around billable calls.  
**cost_per_accepted_second** — total relevant generation cost divided by accepted usable video seconds.  
**Golden Scenario** — canonical behavioral regression scenario.  
**EvidencePack** — distilled, ranked and provenance-carrying research knowledge supplied to the Director.
