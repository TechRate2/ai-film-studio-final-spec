# Vision and Non-Goals

## Vision
Create a generalist film/video brain that converts user intent and references into a production-ready creative plan and finished video, while improving through research evidence, model benchmarks, accepted/rejected revisions and user taste.

Target domains include UGC, reviews, product ads, fashion, horror, romance, comedy, education, documentary/explainer, real estate, news/current factual content, cinematic fantasy, wuxia/xianxia, action, short drama, long film and serialized episodes.

## Desired user experience
1. Upload any relevant media/documents.
2. Describe the desired result naturally.
3. Optionally set budget/quality/language.
4. Review only useful checkpoints/assets/shots.
5. Revise any artifact or shot in natural language.
6. Receive final video and continue the same project/next episode later.

## Quality objective
Maximize narrative/visual quality, retention/purpose, reference fidelity, continuity, first-pass acceptance, model fit and reproducibility. Minimize paid regeneration, unnecessary keyframes, context noise, provider lock-in, unnecessary latency and cost per accepted second.

## Non-goals
- Guarantee virality or universal taste.
- Guarantee pixel-identical characters across arbitrary models.
- Copy protected characters/worlds/expressive content from existing franchises.
- Hide provider/model limitations.
- Pretend every niche uses identical pacing/camera grammar.
- Replace evidence with invented current facts.
- Build every future provider before the first vertical slice works.

## Subsequent independent service
After core release acceptance, users may upload existing video for subtitles only, dubbing only or both. This original-media workflow has its own minimal entry and release gate; no video generation or lip-sync. Its full contract is `spec/47_SOURCE_VIDEO_LOCALIZATION.md`. The main studio's scope is not reduced or delayed by implementing this extension first.
