# Outcome, Taste and Research Memory

## UserTasteProfile
Learn from accepted/rejected versions, revision text, chosen hooks/concepts, preferred camera/acting/VFX density and recurring voice/style choices. Do not overfit from one isolated choice.

## Outcome learning
When analytics exist, store retention/watch-time, CTR, completion, engagement and conversion where applicable. Connect outcomes to creative decisions, not just final files.

## Model learning
Aggregate scenario, prompt structure, duration, active character count, ref count/type, acceptance, failure reason, cost and latency. Update ModelProfile recommendations only from sufficient evidence.

## No weight training initially
Learning is retrieval/memory/benchmark driven.
