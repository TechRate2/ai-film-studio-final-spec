# Model Probe Playbook

Probes convert marketing/unknown behavior into measured ModelProfile evidence.

## Minimum probe suite
1. reference addressing/binding;
2. same-entity multi-view behavior;
3. practical reference count/stability ceiling;
4. stage vs timestamp timing adherence;
5. duration quality curve;
6. camera instruction adherence;
7. multi-event drop behavior;
8. identity/product fidelity;
9. first/end-frame behavior where exposed;
10. continuation/tail-reference behavior;
11. native dialogue/audio quality and language behavior;
12. default unwanted subtitles/music/text behavior;
13. action/VFX complexity limits.

## Controlled comparison
Change one major variable per probe where possible. Save UniversalVideoSpec, compiled prompt, refs, provider/model versions, params, outputs, scores, cost and latency.

## Profile update
Do not promote one lucky/failed sample into global truth. Record confidence/sample count/scenario scope. Conflicting evidence remains visible.

## Re-probe triggers
New model version, provider implementation change, API capability change, large benchmark regression, or significant pricing/routing change.

## Router usage
Router consumes measured scenario performance and uncertainty. Unknown may justify a cheap probe or a safer known route rather than guessing.
